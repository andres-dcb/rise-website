# RISE Remodeling & Renovations

Sprint 1 foundation for the RISE digital showroom.

## Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Foundation included

- Next.js App Router and TypeScript
- Tailwind CSS v4 design tokens
- Responsive navigation and mobile menu
- Reusable Container, Section, Heading, and Button components
- Lenis smooth scrolling with reduced-motion support
- GSAP animation helpers
- Footer and accessibility baseline
- Initial homepage shell for visual verification
